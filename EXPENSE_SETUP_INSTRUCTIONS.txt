EXPENSE MANAGEMENT SETUP INSTRUCTIONS
=====================================

The Expense Management feature has been implemented but needs to be activated.

QUICK SETUP (2 OPTIONS):

OPTION 1 - Using Web Browser (Easiest):
1. Open your browser and go to: http://localhost:8000/setup-expenses.php
2. Wait for the setup to complete
3. Refresh your Laravel app
4. Log in and you'll see "Expense Management" in the sidebar

OPTION 2 - Using Command Line:
1. Open terminal/command prompt
2. Navigate to project directory: cd d:\wampp64\www\urea
3. Run the setup command: php artisan setup:expenses
4. Refresh your browser

OPTION 3 - Manual Database Setup:
If neither option works, you can run these commands manually:
   php artisan migrate
   php artisan db:seed --class=PermissionSeeder
   php artisan db:seed --class=RoleSeeder
